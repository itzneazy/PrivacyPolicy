# Last Stop K3N0

A Discord bot that hosts a classic 1–80 Keno game for the Last Stop community.

## About

Last Stop K3N0 brings a fun, free-to-play Keno experience directly into Discord. Players can join rounds, watch the numbers get called, and compete for the top spots. The bot tracks wins and first-place finishes for leaderboards and stats.

## Features

- 1–80 Keno game
- Automatic round hosting
- Win and placement tracking
- Leaderboard support
- Simple and fast gameplay

## How to Use

1. Make sure the bot is in your server
2. Use the available commands to join or start a Keno round
3. Wait for the numbers to be drawn
4. Check results and climb the leaderboard

*(Command
Description
/keno
Starts a new Keno round (or shows the current one if already active)
/join
Joins the current Keno round
/pick <numbers>
Picks your numbers (example: /pick 3 12 27 41 58)
/numbers
Shows the numbers you picked for the current round
/status
Shows the current game status and how many players have joined
/results
Shows the results of the last completed round
/stats
Shows your personal stats (wins + 1st place finishes)
/leaderboard
Shows the top players by wins or 1st place finishes
/help
Displays the list of available commands)*

## Data Collected

The bot only stores:
- Discord User ID
- Number of wins / 1st place finishes

No emails, payment information, or other personal data is collected.
